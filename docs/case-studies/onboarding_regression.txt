  [supported] The onboarding modal rework in PR #913 (merged 2026-07-14), which shipped with a known unresolved mobile viewport bug blocking the continue button, caused the drop in mobile signups beginning 2026-07-15.
      The timing lines up exactly (merge 14 July, onset 15 July), the PR touches the onboarding flow specifically, and the pre-merge review explicitly identifies a mobile-only blocking bug that was knowingly shipped unfixed. Onboarding completions and mobile sessions/conversions all step down together at the same date.
  [contradicted] The pricing page copy change (commit 77aa21b, merged 2026-07-12) in acme/web caused the drop in signups.
      This commit merged 2026-07-12, two days before the observed onboarding step-change on 2026-07-15; if it were the cause, the drop should have started 12–13 July, but the daily series stays flat through 14 July.
  [inconclusive] A dependabot dependency bump (tailwindcss 4.1.2→4.1.3, commit a41b8c9, merged 2026-07-14) caused the drop.
      This commit merged the same day as PR #913, so timing alone cannot separate the two. However, a routine patch-level CSS framework bump is a much weaker candidate than a rework of the onboarding flow with a documented, reviewer-flagged mobile bug shipped intentionally unfixed. No direct evidence ties this bump to the onboarding funnel, so it is set aside rather than ruled out by a specific observation.
  [supported] No deploys or changes occurred in acme/product that could explain the drop.
      A commit search on acme/product for the window returned zero commits, ruling out a backend/application-side change as the cause.
